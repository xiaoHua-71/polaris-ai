# 7 · 工具对话对接（M5）

> 执行对象：前端仓库 `D:\Project\AIProject\polaris-ai\dev\polaris-ai-front`
> 契约版本：M5，2026-11-16。后端已实现并经 DeepSeek 实测。

## 7.1 目标

新增「工具对话」页面：与现有对话页相同，但调用 `POST /api/chat/tools`，由模型自主决定是否调用后端工具（时间查询、算术计算）。

**非目标**：前端展示工具调用过程（参数 / 结果）、流式工具对话、工具开关。当前接口只返回最终回答。

## 7.2 接口

`POST /api/chat/tools`，请求与 `/api/chat` 相同：

```json
{"message":"现在上海几点了？顺便算一下 (12+3)*4。","conversationId":"22222222-2222-2222-2222-222222222222"}
```

响应（HTTP 200）：

```json
{"content":"现在是上海时间 2026-11-16 22:33:28（UTC+8）；(12+3)*4 = 60。"}
```

语义：

- 后端工具循环同步执行，耗时可能比普通对话长（单次实测约 2–7 秒）；
- 工具异常默认降级：仍返回 200，回答中会说明；
- 轮次超限默认降级：仍返回 200，回答中会说明；
- 参数校验错误与 `/api/chat` 一致（400）。
- 前端 Axios 超时 60s 不变。

## 7.3 前端改造

1. `src/api/chat.ts` 增加 `postChatTools()`（同步 POST，非流式）。
2. 新增 `src/pages/ToolChatPage.tsx`：
   - 复用对话页的布局 / 气泡 / Markdown 渲染样式；
   - 自己维护 `conversationId`（页面打开时生成 UUID，可选 `localStorage` 持久化）；
   - 发送时禁用输入、显示加载态；成功后追加助手消息；
   - 「新会话」清空消息并换 UUID；
   - 记录 422 / 500 等错误，不把英文错误短语直接展示。
3. `src/App.tsx` 增加 `/tools` 路由；`AppShell` 导航增加「工具对话」。

## 7.4 当前可用工具

| 工具 | 会回答的问题示例 |
|---|---|
| `getCurrentTime` | 现在上海 / 纽约几点？今天几号？ |
| `calculate` | (12+3)*4 等于多少？1.5+2.5？ |

模型不一定每次调用工具；简单问题可能直接回答。验证时用需要实时信息或精确计算的问题。

## 7.6 curl 自测

```bash
printf '{"message":"现在上海几点了？顺便算一下 (12+3)*4。","conversationId":"22222222-2222-2222-2222-222222222222"}' > /tmp/tools.json
curl -X POST http://localhost:8103/api/chat/tools \
  -H 'Content-Type: application/json' \
  --data-binary @/tmp/tools.json
```
